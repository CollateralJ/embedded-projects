# Multi-functional Shield PCB Design

For this project, I was tasked with taking all of my previous ATMega328PB projects and fitting all of the components necessary for them to function to an Arduino compatible multi-functional shield. The whole process is detailed in [the report](https://github.com/CollateralJ/embedded-projects/blob/main/PCB_multifunctional_shield_design/PCB_multifunctional_shield_design.pdf).

\
This PCB would add LEDs, push buttons, a potentiometer, a 7-segment display, headers for motor connections, an OLED display, and a BMI160 inertial measurement unit for plug and play use with my embedded projects!

\
Previous projects implemented via this PCB: [ultrasonic sensor radar](https://github.com/CollateralJ/embedded-projects/tree/main/servo_motor_ultrasonic_sensor_radar_7-segment_SPI_UART), [inertial measurement](https://github.com/CollateralJ/embedded-projects/tree/main/IMU_OLED_gyro_accelerometer_I2C_UART), [motor control](https://github.com/CollateralJ/embedded-projects/tree/main/DC_motor_UART_PWM_ADC_POT), [UART](https://github.com/CollateralJ/embedded-projects/tree/main/IMU_OLED_gyro_accelerometer_I2C_UART), [PWM](https://github.com/CollateralJ/embedded-projects/tree/main/simple_PWM).
