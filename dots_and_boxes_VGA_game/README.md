# Dots and Boxes Through Direct VGA Connection

![Game](https://github.com/CollateralJ/embedded-projects/blob/main/dots_and_boxes_VGA_game/game_photo.png "")

An extremely challenging project creating a 3 player version of the pen and paper game "Dots and Boxes", entirely in VHDL, and with no libraries for displaying via VGA. Each cycle, after game data is stored, the Altera DE2 FPGA iterates over every pixel to determine if it should be on. Pure datasheet display magic.

Check out [the report](https://github.com/CollateralJ/embedded-projects/blob/main/dots_and_boxes_VGA_game/tutorial_report.pdf) for a detailed step-by-step tutorial, or just to get a glimpse of how it turned out!
