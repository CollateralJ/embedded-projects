# Whack a Mole on LCD Screen

This project uses a custom ATMega328PB to run a whack a mole program. The LCD displays the game state, with moles raising out of their holes for anywhere from 1/3 of a second to 2 seconds. The score is kept, displayed at the end, and the player has 3 lives.
